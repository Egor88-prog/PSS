Опыт 7. Относительное смещение

Обычной карточке задано position: relative; top: 1rem.

Что меняем

Исходное значение: .card { position: static } — значение по умолчанию

Изменённое значение, файл exp07.css: .card--shift { position: relative; top: 1rem }

Видимый результат

Карточка с классом card--shift опустилась на 16 px: её верхняя граница перешла с отметки 0 на отметку 16. При этом следующая карточка осталась на своём месте — она не сдвинулась вместе с ней, и пустая строка между карточками исчезла.

Объяснение

relative оставляет элемент в потоке: место под него резервируется, как обычно. Смещение создаётся только визуально, поэтому соседние элементы не меняют положение. У static значения top, right, bottom и left вообще не действуют.

Стенд

1. Исходный вариант — static

Карточка до

Обычное положение в сетке.

Карточка после

Стоит на своём месте в той же строке.

2. Изменённый вариант — relative; top: 1rem

Карточка до

Не изменилась.

Карточка после

Сместилась вниз на 16 px, но место в сетке за ней сохранилось.
