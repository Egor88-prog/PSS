Что меняем

Исходное значение: .menu { flex-direction: row }

Изменённое значение, файл exp02.css: .menu--column { flex-direction: column } и высокая рамка min-height: 20rem

Видимый результат

При row пункты выстроены по горизонтали, а justify-content: center собирает их ряд и центрирует по горизонтали. При column пункты выстраиваются сверху вниз и центрируются по горизонтали, а свободное место теперь распределяется justify-content по вертикали: в высокой рамке группа пунктов уходит вниз от верхней границы.

Объяснение

flex-direction задаёт направление главной оси. justify-content работает вдоль главной оси, align-items — вдоль поперечной. Поэтому смена направления меняет и то, вдоль чего распределяется свободное место, хотя сами свойства не менялись.
