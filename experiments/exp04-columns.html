Опыт 4. Колонки Grid

Отношение колонок 2fr 1fr заменено на 1fr 1fr, minmax(0, ...) сохранено.

Что меняем

Исходное значение: .layout { grid-template-columns: minmax(0, 2fr) minmax(0, 1fr) }

Изменённое значение, файл exp04.css: .layout--equal { grid-template-columns: minmax(0, 1fr) minmax(0, 1fr) }

Видимый результат

При 2fr 1fr основной блок занимает 731 px, а aside — 365 px. При 1fr 1fr оба блока равны: по 548 px. Сумма колонок в обоих случаях одинакова — 1096 px, потому что свободное место делится после вычета gap: 1.5rem.

Объяснение

Единица fr обозначает долю свободного пространства, а не фиксированный размер. Поэтому 1fr 1fr даёт равные колонки, а 2fr 1fr — отношение 2:1. minmax(0, ...) разрешает колонке сжиматься уже ширины её содержимого; сам длинный текст при этом всё равно нужно переносить или прокручивать.

Стенд

1. Исходный вариант — 2fr 1fr

Основное содержимое

Левая колонка сетки. При 2fr она занимает две трети свободного места.

Дополнительные сведения

Правая колонка сетки, в неё попадает содержимое aside.

2. Изменённый вариант — 1fr 1fr

Основное содержимое

Та же разметка, но колонки получили равные доли свободного места.

Дополнительные сведения

Блок aside стал такой же ширины, как основной блок.
