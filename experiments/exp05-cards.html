Опыт 5. Сетка карточек

repeat(2, minmax(0, 1fr)) заменено на repeat(3, minmax(0, 1fr)).

  • Все опыты
  • Сайт мастерской
  • В начало страницы

Что меняем

Исходное значение: .cards { grid-template-columns: repeat(2, minmax(0, 1fr)) }

Изменённое значение, файл exp05.css: .cards--three { grid-template-columns: repeat(3, minmax(0, 1fr)) }

Видимый результат

При двух колонках карточки стоят парами: первая и вторая в первой строке, третья и четвёртая — во второй. При трёх колонках первая строка вмещает три карточки, а четвёртая переходит на вторую строку в первую колонку, то есть в порядке HTML. Порядок чтения не меняется, меняется только точка переноса.

Объяснение

Без явного размещения Grid заполняет сетку по порядку исходного кода: элементы занимают ячейки слева направо, затем переходят на следующую строку. Чтобы растянуть карточку на всю строку, ей задают grid-column: 1 / -1.
