Опыт 8. Абсолютная метка

У карточки featured отключено position: relative.

Что меняем

Исходное значение: .featured { position: relative }, метка .badge { position: absolute; top: 1rem; right: 1rem }

Изменённое значение, файл exp08.css: .featured--static { position: static } и рамка .demo-box { position: relative }

Видимый результат

  • Обычная карточка featured: метка «Сезонное» стоит в правом верхнем углу карточки на расстоянии 1 rem от краёв.
  • Карточка featured--static в обычном потоке: метка исчезла из карточки и оказалась в правом верхнем углу окна — теперь её положение задаёт начальный содержащий блок страницы.
  • Та же карточка внутри рамки demo-box с position: relative: метка вернулась внутрь рамки, потому что ближайшим позиционированным предком стала рамка.

Объяснение

absolute исключает элемент из потока, а отсчёт ведётся от ближайшего предка, у которого position отличен от static. Если такого предка нет, отсчёт идёт от начального содержащего блока — это и есть угол окна. Содержащий блок могут задавать и другие свойства предков, например transform.
