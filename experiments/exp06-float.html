Опыт 6. Обтекание

Сравниваются float: left, float: right, float: none и абзац с clear: both.

  • Сайт мастерской
  • В начало страницы

Что меняем

Исходное значение: .story-image { float: left }, у абзаца .after-image { clear: both }

Изменённые значения, файл exp06.css: .story-image--right { float: right } и .story-image--none { float: none }

Видимый результат

  • float: left — строки абзаца идут справа от фотографии, их ширина около 442 px вместо 660 px.
  • float: right — строки идут слева, фотография прижата к правому краю.
  • float: none — фотография вернулась в обычный поток, текст занимает всю ширину, высота заметки выросла с 526 до 663 px.
  • clear: both — абзац с классом after-image начинается ниже фотографии; без этого правила он продолжил бы обтекание.

Объяснение

Плавающий элемент вынут из обычного блочного потока, но продолжает влиять на доступное место для строк текста, поэтому float не равнозначен absolute. Контейнер заметки имеет display: flow-root: он создаёт новый блочный контекст форматирования и учитывает высоту плавающего потомка. clear: both переносит блок ниже плавающих элементов с обеих сторон в том же контексте.

Стенд

1. Исходный вариант — float: left

Строки этого абзаца обтекают фотографию справа, поэтому он заметно уже остального текста заметки.

Этот абзац имеет класс after-image с правилом clear: both, поэтому он начинается ниже фотографии и снова занимает всю ширину.

2. Изменённый вариант — float: right

Теперь строки обтекают фотографию слева, а сама она прижата к правому краю заметки.

Абзац с clear: both ведёт себя так же: он переносится ниже плавающего элемента.

3. Изменённый вариант — float: none

Фотография вернулась в обычный поток, обтекания нет, и оба абзаца занимают всю ширину заметки.

Правило clear: both здесь ничего не меняет: рядом нет плавающих элементов, поэтому абзац остаётся на своём месте.

4. Разница между абзацем с clear: both и без него

Короткий абзац: он занимает две строки рядом с фотографией.

Абзац с классом after-image начинается ниже нижней границы фотографии.

Короткий абзац: он занимает две строки рядом с фотографией.

Такой же абзац без класса after-image продолжает обтекание и начинается на одной высоте с коротким абзацем.
