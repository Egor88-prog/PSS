Опыт 1. Обычный поток

У меню временно заменено display: flex на display: block.

  • Все опыты
  • Сайт мастерской
  • В начало страницы

Что меняем

Исходное значение: .menu { display: flex }

Изменённое значение, файл exp01.css: .menu--block { display: block }

Видимый результат

В варианте с flex тринадцать пунктов меню занимают три строки, высота блока меню — 149 px. В варианте с block каждый пункт начинается с новой строки, строк тринадцать, высота — 538 px.

Объяснение

Обычный поток складывает блочные элементы сверху вниз. Элементы li — блочные, поэтому без display: flex на родителе каждый пункт занимает всю ширину контейнера и начинается с новой строки. Ширина пункта при этом равна ширине контейнера, а не ширине текста.
