Что меняем

Исходное значение: .menu { flex-wrap: wrap }, при ширине не более 48 rem действует flex-direction: column

Изменённое значение, файл exp03.css: .menu { flex-direction: row; align-items: center } (медиазапрос отключён) и .menu--nowrap { flex-wrap: nowrap } для второго стенда

Порядок работы

  1. Сузьте окно до 768 и затем до 375 CSS-пикселей — стенд специально оставлен в широкоэкранном виде.
  2. Сравните верхний и нижний варианты: с переносом и без него.

Видимый результат

С wrap длинный пункт переносится на следующую строку целиком, меню занимает две строки. С nowrap строка не переносится, длинный пункт упирается в правый край, и рамка стенда показывает горизонтальную прокрутку — текст уходит за пределы окна.

Объяснение

flex-wrap: nowrap запрещает перенос: пункты остаются на одной главной оси. Поскольку flex-элементы умеют сжиматься, короткие пункты сжимаются, а длинный текст без разрешения переноса выдавливает строку за границу контейнера. wrap разрешает перенос на дополнительные строки — но работает одна ось за раз, поэтому колонки между строками могут отличаться.
